Problema de producción

Validar el render antes de que llegue a composición

La herramienta lee directamente la estructura EXR, conserva los canales desconocidos, distingue datos de color y técnicos, calcula métricas con precisión segura y aplica reglas configurables sin obligar al artista a elegir manualmente entre archivos simples y multilayer.

  1. 01Descubrir

    Localiza archivos con patrones, búsqueda recursiva, profundidad y límite de frames.

  2. 02Inspeccionar

    Describe resolución, canales, AOVs, partes y estructuras no compatibles.

  3. 03Leer

    Abre una vez cada frame compatible y conserva todos los componentes requeridos.

  4. 04Validar

    Detecta datos no finitos, AOVs vacíos, extremos, cambios y discontinuidades.

  5. 05Reportar

    Devuelve la misma evidencia mediante GUI, CLI, JSON y HTML.

Correcciones actuales

Resultados útiles, sin falsos positivos de Cryptomatte

Crypto

IDs separados del color

Los metadatos estándar identifican capas Cryptomatte. Sus IDs no contaminan la luminancia ni los outliers temporales.

1–800

Rango esperado

Un rango inclusivo permite detectar también frames ausentes al principio o al final de una entrega.

float64

Acumulación precisa

Las sumas y promedios por canal usan precisión de 64 bits para HDR y secuencias largas.

Todos

Canales conservados

AOVs desconocidos y pases depth, mask o scalar multicanal retienen todos sus componentes para diagnóstico.

Cryptomatte sigue recibiendo diagnósticos objetivos por canal, como NaN e infinito; solamente se excluyen interpretaciones que no tienen sentido para IDs codificados, como luminancia o magnitud extrema.

Arquitectura verificable

Un pipeline construido alrededor de datos estructurados

Fuente EXR→Descubrimiento→Lector OpenEXR→Modelos canónicos→Motor de reglas→Reporte

AnalysisReport es el contrato entre procesamiento y presentación. Contiene inspecciones, métricas agregadas y por frame, hallazgos, diagnóstico de secuencia y errores de lectura explícitos.

Las reglas se configuran mediante TOML o JSON. La sección [aov_categories] permite clasificar nombres específicos de un renderer o estudio sin perder canales desconocidos.

Alcance transparente

Capacidades claras y limitaciones honestas

Disponible actualmente

  • EXR RGB/RGBA y archivos multilayer con AOVs nombrados
  • Color, scalar, vector, mask, depth, Cryptomatte y unknown
  • NaN, infinitos, negativos, extremos, AOVs vacíos y canales constantes
  • Continuidad, duplicados, padding y rango esperado de secuencia
  • Mediana, MAD, cambio temporal y outliers de luminancia
  • Comparación con reportes baseline y exportación JSON/HTML
  • Cancelación cooperativa y diagnóstico de frames corruptos

Limitaciones deliberadas

  • Deep EXR y el análisis completo multipart se detectan, pero no se procesan
  • La clasificación Cryptomatte depende de sus metadatos estándar o de un preset
  • Los pases técnicos no reciben interpretación artística específica del renderer
  • Los umbrales deben calibrarse para cada show y configuración de render
  • La herramienta apoya el juicio artístico; no lo sustituye

Inicio rápido

Inspeccionar y analizar EXR reales

uv sync --python 3.12 --extra dev
uv run aovguard inspect-structure "C:\ruta\render.exr"
uv run aovguard check-sequence "C:\ruta\renders" --expected-frame-range 1 800
uv run aovguard analyze "C:\ruta\renders" --expected-frame-range 1 800 --json reports\reporte.json --html reports\reporte.html
uv run aovguard-ui
