Production problem

Validate renders before they reach compositing

The tool reads EXR structure directly, preserves unknown channels, separates color from technical data, computes metrics with safe precision, and applies configurable rules without forcing artists to choose manually between simple and multilayer files.

  1. 01Discover

    Find files using patterns, recursive search, depth, and frame limits.

  2. 02Inspect

    Describe resolution, channels, AOVs, parts, and unsupported structures.

  3. 03Read

    Open each compatible frame once and retain every required component.

  4. 04Validate

    Detect non-finite data, empty AOVs, extremes, changes, and discontinuities.

  5. 05Report

    Return the same evidence through the GUI, CLI, JSON, and HTML.

Current corrections

Useful results without Cryptomatte false positives

Crypto

IDs separated from color

Standard metadata identifies Cryptomatte layers. Their IDs do not contaminate luminance or temporal outliers.

1–800

Expected range

An inclusive range detects frames missing from the beginning or end of a delivery as well as internal gaps.

float64

Precise accumulation

Per-channel sums and averages use 64-bit precision for HDR data and long sequences.

All

Channels preserved

Unknown AOVs and multichannel depth, mask, or scalar passes retain every component for diagnostics.

Cryptomatte still receives objective per-channel diagnostics such as NaN and infinity checks. Only interpretations that are meaningless for encoded IDs, such as luminance or generic extreme magnitude, are excluded.

Verifiable architecture

A pipeline built around structured data

EXR source→Discovery→OpenEXR reader→Canonical models→Rule engine→Report

AnalysisReport is the contract between processing and presentation. It contains inspections, aggregate and per-frame metrics, findings, sequence diagnostics, and explicit read errors.

Rules are configured through TOML or JSON. The [aov_categories] section classifies renderer- or studio-specific names without losing unknown channels.

Transparent scope

Clear capabilities and honest limitations

Available now

  • RGB/RGBA EXRs and multilayer files with named AOVs
  • Color, scalar, vector, mask, depth, Cryptomatte, and unknown categories
  • NaN, infinities, negatives, extremes, empty AOVs, and constant channels
  • Continuity, duplicates, padding, and expected sequence ranges
  • Median, MAD, temporal change, and luminance outliers
  • Baseline report comparison and JSON/HTML export
  • Cooperative cancellation and corrupt-frame diagnostics

Deliberate limitations

  • Deep EXR and full multipart analysis are detected but not processed
  • Cryptomatte classification depends on standard metadata or a preset
  • Technical passes do not receive renderer-specific artistic interpretation
  • Thresholds must be calibrated for each show and render setup
  • The tool supports artistic judgment; it does not replace it

Quick start

Inspect and analyze real EXR files

uv sync --python 3.12 --extra dev
uv run aovguard inspect-structure "C:\path\render.exr"
uv run aovguard check-sequence "C:\path\renders" --expected-frame-range 1 800
uv run aovguard analyze "C:\path\renders" --expected-frame-range 1 800 --json reports\report.json --html reports\report.html
uv run aovguard-ui
